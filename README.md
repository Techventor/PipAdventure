# 🎮 Pip 的冒险 (Pip Adventure)

一个纯前端单文件横版跳跃游戏。角色、关卡、音效全部程序生成，无任何外部资源，可离线运行。

## ✨ 特性

- 🎨 **三大主题关卡**：阳光草原、落日台地、月光洞窟
- 🎵 **程序生成音效与背景音乐**：使用 Web Audio API，无需外部音频文件
- 📱 **触屏支持**：移动端自动显示虚拟按键
- 💾 **本地存档**：自动保存最高分
- 🚀 **零依赖**：单个 HTML 文件即可运行

## 🕹️ 操作

| 按键 | 功能 |
|------|------|
| `←` `→` / `A` `D` | 移动 |
| `空格` / `W` / `↑` | 跳跃 |
| `P` / `Esc` | 暂停 |
| `R` | 重来 |
| `M` | 静音 |

## 🚀 开始游戏

直接在浏览器中打开 `index.html` 即可开始游戏！

## 📸 截图

游戏包含三个精心设计的关卡：
1. **阳光草原** - 入门关卡，学习基本操作
2. **落日台地** - 难度提升，更多敌人和陷阱
3. **月光洞窟** - 终极挑战，尖刺和移动平台
